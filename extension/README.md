# AQW Companion Extension — experimental v0.1.0

Load only the `extension` directory using Developer mode > Load unpacked in Opera or Chrome. No account or inventory access. The popup links to the Companion connection diagnostic and Wiki. The connection page must be deployed before the handshake can be tested. The Wiki badge confirms injection independently. All permissions are limited to the two declared HTTPS content-script match patterns; no additional permissions, background access or data storage. Not published to browser stores.

After updates, reload the extension in the browser's extensions manager and refresh both pages.
