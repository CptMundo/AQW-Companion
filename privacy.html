Privacy & Visit Statistics

Last updated: 25 November 2026

AQW Companion is an unofficial fan-made utility for AdventureQuest Worlds (AQW), maintained by CptMundo. It is not affiliated with Artix Entertainment.

Your game data stays in your browser

Inventory exports, wishlist entries, goals, Forge unlocks and saved progress are processed and stored locally on your device where browser storage is available. AQW Companion does not transmit your inventory files, account exports or personal backups to a server operated by the project. If you share an export yourself, that choice is yours.

Optional browser extension

The extension can export Inventory and Bank records from the signed-in Account Manager after a user click. The optional on-page button requires permission for the account.aq.com origin; its scripts are registered only for the Inventory page. It uses the browser’s existing session for read-only requests, without reading or storing login credentials or cookies. Records are staged locally and imported into Companion only on confirmation. You may revoke the optional permission in the extension popup or browser settings. Manual JSON import remains available.

On supported Wiki quest and shop pages, the optional Show inventory status button compares explicitly linked names with the local snapshot and displays stock labels. Inventory is not sent to the Wiki server by this feature. Visible labels are rendered on the Wiki page; closed shadow roots are not a security boundary. Refresh or close the page to remove the displayed labels.

Wiki tools load automatically on supported pages. Ownership lookup runs only on individual item pages against the local snapshot; item category indexes have no ownership lookup or inline inventory labels. The optional category Wishlist search reads item links only after an explicit search, and sends a public item name and Wiki slug to the local queue only when you click Add. No inventory is sent to the Wiki server by these features. Visible labels are not a security boundary against the host page.

Wishlist and Tracker queue actions store only public item/quest names and Wiki slugs locally until Companion imports them; no automatic game actions. No inventory or tracker data is uploaded by these features. Inventory Cleanup uses local data and catalog references; it never deletes game items.

The extension popup can display a compact snapshot of the Companion’s saved Wishlist and recurring tracker: public item and task names, local task IDs, saved map commands, tracked percentages, manual check states, current tracking periods and the snapshot timestamp. The extension reads the existing planner storage on the Companion page and stores this limited snapshot locally. Only the extension popup can request the entire mini-tracker snapshot. When you explicitly mark or unmark a recurring task in the popup, the extension queues its local task ID, reset period and requested check state. The Companion site applies it to the same local tracker only for an eligible pinned task in the current period, and acknowledges the result. No game actions or remote uploads occur. Manual checks are not proof of in-game completion.

The extension requests storage for local preferences and snapshots, activeTab and scripting for user-initiated Account Manager capture, and optional account.aq.com access for the on-page export button. It processes public Wiki content and images to provide its tools. The extension does not execute remotely hosted JavaScript. The project uses the data only to provide the disclosed features, not for advertising, sale or unrelated profiling. The use of user data adheres to the Chrome Web Store User Data Policy, including its Limited Use requirements.

Badge Hunter

Badge progress and backup files remain in your browser. Public badge artwork is loaded from original image hosts as you browse the catalog; those hosts may receive normal network information such as your IP address. The image requests do not contain your saved badge state or inventory. The catalog links to public Wiki and official game sources.

Character Page badge capture runs after clicking Capture badges in the extension on the public Character Page. It collects the displayed character identifier and badge image filenames and labels, stages them locally, and shares the staged capture with the Companion website when requested by its Badge Hunter. Confirm the matches before saving. No credentials, cookies or private account data are collected by this feature. Staged and imported matches can be cleared separately. No new host permissions are required.

Cookie-free visit statistics

We use Umami Cloud to understand website visits, approximate geographic location, referring websites, and browser and device statistics. Umami processes network information to estimate location; its standard analytics records do not store the visitor IP address as a field. Visit statistics do not use analytics cookies.

Only a pageview of the Companion landing page is requested. We exclude query parameters and fragments and do not send inventory contents, Wishlist entries, character names, uploaded files, custom events or session replay data. Umami is a third-party service; see Umami privacy information.

Visitors who previously declined analytics, or whose browser signals Global Privacy Control or Do Not Track, are excluded from this integration. Browser content blockers may also prevent collection. You can disable measurement by enabling a supported privacy signal in your browser.

Analytics data retention

Visit statistics are subject to Umami Cloud's retention settings and terms. Previously collected Google Analytics data is not migrated to Umami; removal of the Google tag does not delete historical records or existing cookies.
